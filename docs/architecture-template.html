2. Storage Scaling
Tiered Data, Caching & Object Stores
PostgreSQL Read/Write Split ACID Compliant
Primary instance handles atomic bookings, calendar blocks, and price mutations. Scalable read-replica cluster behind PgBouncer handles listing queries.
Aurora PostgreSQL PgBouncer Row Sharding
Redis Cluster In-Memory Cache < 2ms Latency
Distributed Redis cluster for calendar availability matrices, dynamic night pricing calculations (₹28,499), rate limiting, and guest reservation locks.
Redis 7 Cluster Sharding Pub/Sub Eviction
Object Storage (S3 / R2) 99.999999999% Durability
High-durability geo-replicated object storage for listing assets, host avatars, and 43 original RAW property photos with automated lifecycle archiving.
AWS S3 Cloudflare R2 Multipart Upload
CDC Event Streaming Zero Read Impact
Debezium captures PostgreSQL WAL events and streams mutations to Apache Kafka to synchronize search engines and cache invalidation instantaneously.
Kafka Debezium CDC Event-Driven
3. Search Scaling
Geospatial, Filtering & Ingestion
Elasticsearch Cluster Distributed Indexing
Dedicated master and data nodes partitioned across multi-AZs. Inverted index indexing millions of stay listings, reviews, and host metadata.
Elasticsearch 8 Sharded Indices Read Replicas
Geospatial Spatial Search Radius & Polygon
Geo-point indexing on coordinates (Lat: 15.5186, Lng: 73.7634) allowing sub-millisecond bounding box and radius queries for Candolim & North Goa stays.
Geo-Distance Geo-Hash Map Clustering
Multi-Facet Filtering Engine < 30ms Complex Filter
Fast boolean querying over dates (Oct 18-23, 2026), guest counts (3 guests), amenities (Jacuzzi, Pool, AC), price ranges, and "Guest favourite" status.
Bitset Caching BM25 Scoring Facet Aggregations
Real-time Ingestion Stream < 500ms Replication
Kafka streaming consumer updates Elasticsearch document records asynchronously within 500ms of any booking or listing change without DB query spikes.
Kafka Consumer Bulk Indexer Near Real-Time
